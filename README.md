# 🦊 Fox Stanze

Handy-App für die Göpfert-Flachbettstanze (Wellpappe) bei Seyfert.

- **🧰 Rüsten** – Rüstblatt pro Artikel (Anleger, Stanze, Ausbrechstation, Bogenablager, Auslauf, Stopperüberwachung), eigene Werte, Fotos, Notizen
  - 📷 **Werte vom Bildschirm-Foto** – Zahlen werden offline erkannt (ML Kit), du tippst sie den Feldern zu
  - 🕓 **Verlauf** – jede Änderung wird gemerkt, geänderte Felder orange mit „vorher“-Wert, Versionen wiederherstellen
  - ⏱️ **Rüst-Stoppuhr** mit Ø-Rüstzeit pro Artikel
  - ▦ **QR-Etiketten** zum Aufkleben, Scannen öffnet das Rüstblatt
  - 📄 **Rüstblatt als PDF**
- **📋 Schicht** – Bogen, Ausstoß, Störungen, Übergabe-Text, 📊 Statistik (Bogen pro Tag, häufigste Störungen, nach Schicht), PDF-Bericht, CSV für Excel
- **📖 Wissen** – Erklärungen, Quiz, ✅ Rüst-Checkliste (anpassbar), 🛠️ Fehlerbibliothek
- **🧮 Rechner** – Restzeit mit 🔔 Erinnerung vor Auftragsende, Nutzen, Stapel

Alle Daten bleiben auf dem Handy. Über ⋯ gibt es Export und Sicherung.
