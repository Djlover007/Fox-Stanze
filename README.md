# 🦊 Fox Stanze

Handy-App für die Göpfert-Flachbettstanze (Wellpappe) bei Seyfert.

- **🧰 Rüsten** – Rüstblatt pro Artikel: Anleger, Stanze (Spalt, Druck), Ausbrechstation, Bogenablager, Auslauf, Stopperüberwachung, eigene Werte, Fotos, Notizen
- **📋 Schicht** – Bogen, Ausstoß, Störungen mit Minuten, Übergabe-Text zum Kopieren, 7-Tage-Übersicht
- **📖 Wissen** – Erklärungen zu jedem Bildschirm, eigene Notizen, Quiz für Azubis
- **🧮 Rechner** – Restzeit bis Auftragsende, Stück aus Nutzen, Bogen im Stapel

Alle Daten bleiben auf dem Handy. Über ⋯ lässt sich eine Sicherung teilen und wieder einspielen.

## APK
Jeder Push baut automatisch eine neue APK → **Releases** → `Fox-Stanze.apk`.
